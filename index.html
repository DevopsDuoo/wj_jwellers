Thermal Barcode Printer Setup Guide

Calibration instructions for TSC, Zebra, TVS & Honeywell 86mm × 15mm labels.

1. Mechanical Label Media Dimensions

  • Width: 86.0 mm (56mm Printable Blade + 30mm Dumbbell Looping Tail)
  • Height: 15.0 mm
  • Sensor Gap / Notch: 3.0 mm between consecutive labels
  • Total Feed Pitch (Repeat): 18.0 mm

2. Driver & Print Dialog Settings (Ctrl+P / Cmd+P)

  • Destination: Select your thermal printer (e.g. TSC DA210, Zebra ZD230, TVS LP 46 Neo).
  • Paper Size: Choose user-defined 86mm × 15mm (or 3.38" × 0.59").
  • Margins: Set strictly to None (0 mm).
  • Headers & Footers: Uncheck (disabled).
  • Scale: Set to 100% (Default).
TSC Printers (DA210 / TE200)

In DiagTool or driver: Sensor Type = Transmissive / Gap. Gap Size = 3.0mm. Print Speed = 2.0 - 3.0 ips. Darkness = 12-14 for resin ribbon.

Zebra Printers (ZD220 / ZD230)

In Zebra Setup Utilities: Media Type = Mark / Web Sensing. Calibrate media feed. Darkness = 18-22. Dither = None (Black/White Threshold).

3. Upper-Side Text Cutting? Easy 3-Step Fix

Thermal barcode rolls have a 2mm–3mm physical sensor gap. If your printer roller has a slight lead offset, the top line (e.g. Item Name, Customer Name, or Store Name) might touch the top edge:

  • Use Top Shift Dropdown: Select +1.8 mm (Default) or +2.2 mm in the queue toolbar. This moves the top line down into the safe printable area.
  • Print Dialog Margins: In Chrome/Edge, ensure Margins are set to None and Scale is 100%.
  • 1-Minute Sensor Gap Calibration: Turn printer power OFF → Hold down the FEED / PAUSE button → Turn printer power ON while holding button → Release when the printer beeps and feeds 2-3 blank labels. The printer will accurately lock onto the label gap!

Ribbon Protection Tip: The 30mm looping tail is configured as strictly ink-free in this generator. The thermal head will omit heating on the tail, saving thermal ribbon while keeping the label loop clean and non-stick.
